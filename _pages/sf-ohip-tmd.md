**SF-OHIP-TMD** is an 8-item, four-factor short-form patient-reported outcome measure for assessing oral health impact in temporomandibular disorders.

It was developed and validated as a brief alternative to the original OHIP-TMD while preserving multidimensional assessment of TMD-specific oral health-related quality of life.

## Why SF-OHIP-TMD?

Temporomandibular disorders affect patients through pain, jaw function limitation, psychological distress, and social impairment. Existing instruments can be too long for routine clinical monitoring, longitudinal follow-up, large-scale research, and repeated digital assessment.

SF-OHIP-TMD was designed to reduce respondent burden while retaining clinically meaningful multidimensional information.

## Key features

| Feature           | Description                                                  |
| ----------------- | ------------------------------------------------------------ |
| Length            | 8 items                                                      |
| Structure         | Four factors                                                 |
| Domains           | Psychological impact, social impact, oral function, orofacial pain |
| Source instrument | OHIP-TMD                                                     |
| Intended use      | TMD-specific oral health-related quality of life assessment  |
| Suitable settings | Clinical monitoring, longitudinal studies, epidemiological research, digital health assessment |

## SF-OHIP-TMD Items and Scoring

The SF-OHIP-TMD consists of eight items selected from the OHIP-TMD. It covers four domains: Psychological Impact, Social Impact, Oral Function, and Orofacial Pain.

### Administration instruction

Over the last month, how often have you experienced the following impacts because of problems with your jaws, teeth, or mouth?

Each item is rated using the standard OHIP response scale:

| Response option | Score |
|---|---:|
| Never | 0 |
| Hardly ever | 1 |
| Occasionally | 2 |
| Fairly often | 3 |
| Very often | 4 |

### Scoring

Each item is scored from 0 to 4:

| Response option | Score |
|---|---:|
| Never | 0 |
| Hardly ever | 1 |
| Occasionally | 2 |
| Fairly often | 3 |
| Very often | 4 |

The SF-OHIP-TMD total score is calculated by adding the scores of all eight items.

The total score ranges from 0 to 32, with higher scores indicating greater TMD-related oral health impact.

Each domain contains two items. The domain score is calculated by adding the scores of the two items within that domain, so each domain score ranges from 0 to 8:

### Suggested reporting format

When reporting SF-OHIP-TMD results, we recommend presenting both the total score and the four domain scores:

| Score | Range |
|---|---:|
| SF-OHIP-TMD total score | 0–32 |
| Psychological Impact score | 0–8 |
| Social Impact score | 0–8 |
| Oral Function score | 0–8 |
| Orofacial Pain score | 0–8 |

The total score provides a global index of TMD-specific oral health impact, whereas the domain scores help characterize the main source of patient burden.

### Use notice

The SF-OHIP-TMD is derived from the OHIP-TMD. Users should cite the original OHIP-TMD publication and the SF-OHIP-TMD validation study when using this short form.

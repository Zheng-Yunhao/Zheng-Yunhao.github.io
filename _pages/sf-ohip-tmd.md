# SF-OHIP-TMD

**SF-OHIP-TMD** is an 8-item, four-factor short-form patient-reported outcome measure for assessing oral health impact in temporomandibular disorders.

It was developed and validated as a brief alternative to the original OHIP-TMD while preserving multidimensional assessment of TMD-specific oral health-related quality of life.

## Why SF-OHIP-TMD?

Temporomandibular disorders affect patients through pain, jaw function limitation, psychological distress, and social impairment. Existing instruments can be too long for routine clinical monitoring, longitudinal follow-up, large-scale research, and repeated digital assessment.

SF-OHIP-TMD was designed to reduce respondent burden while retaining clinically meaningful multidimensional information.

## Key features

| Feature           | Description                                                  |
| ----------------- | ------------------------------------------------------------ |
| Length            | 8 items                                                      |
| Structure         | Four factors                                                 |
| Domains           | Psychological impact, social impact, oral function, orofacial pain |
| Source instrument | OHIP-TMD                                                     |
| Intended use      | TMD-specific oral health-related quality of life assessment  |
| Suitable settings | Clinical monitoring, longitudinal studies, epidemiological research, digital health assessment |

## Four-domain structure

| Domain               |      OHIP-TMD item numbers | Domain score range |
| -------------------- | -------------------------: | -----------------: |
| Psychological impact |                     15, 17 |                0–8 |
| Social impact        |                     20, 22 |                0–8 |
| Oral function        |                       1, 6 |                0–8 |
| Orofacial pain       |                       5, 7 |                0–8 |
| Total score          | 1, 5, 6, 7, 15, 17, 20, 22 |               0–32 |

Each item uses the standard OHIP response format from 0 to 4. Higher scores indicate greater TMD-related oral health impact.

## How to use SF-OHIP-TMD

1. Identify eligible patients with TMD using DC/TMD or another clearly defined diagnostic framework.
2. Administer the 8 selected OHIP-TMD items.
3. Score each item from 0 to 4.
4. Sum all 8 items to obtain the total score.
5. Sum the two items within each domain to obtain domain-specific scores.
6. Interpret higher scores as greater negative oral health impact.

## Important note on access

Because SF-OHIP-TMD is derived from the OHIP-TMD/OHIP instrument family, the full item wording is not displayed on this page. Researchers who wish to use the instrument should cite the validation paper and contact the authors or relevant rights holder to confirm permission for their intended use.
